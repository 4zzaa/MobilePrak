# Logo

Logo shopping_bag diimpor dari Google Material Design Icons, bukan dibuat dengan AI.

- Sumber: https://github.com/google/material-design-icons/blob/master/png/action/shopping_bag/materialicons/48dp/2x/baseline_shopping_bag_black_48dp.png
- Lisensi: Apache License 2.0, https://www.apache.org/licenses/LICENSE-2.0
- Copyright Google LLC.

File asli dipakai sebagai `logo.png`, favicon web, dan ikon launcher Android.
Logo pada header memakai `Icons.shopping_bag_outlined` dari import
`package:flutter/material.dart`. Tidak menggunakan paket Cupertino Icons.
